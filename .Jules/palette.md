## 2025-05-14 - Visually de-emphasizing completed tasks
**Learning:** Completed tasks should be visually de-emphasized to reduce cognitive load and help users focus on remaining items. Using a gray foreground with a background that matches the theme ensures both accessibility (WCAG AA) and clear distinction from active tasks.
**Action:** When implementing task lists, always include a 'done' state that uses de-emphasized colors (e.g., #595959 for light, #a9a9a9 for dark) and ensure it takes precedence over other visual markers like priority.
