## 2026-07-15 - Visual Hierarchy of Completed Tasks and Theme Consistency
**Learning:** In a priority-colored Treeview, completed tasks need strong, accessible visual de-emphasis (graying out) that overrides the bright priority background colors. Prepending a 'done' tag in Tkinter's Treeview ensures visual precedence. In light mode (background `#f8f9fa`), using `#595959` foreground on a white/neutral background offers proper de-emphasis and WCAG AA contrast (~6.6:1). In dark mode (background `#212529`), using `#a9a9a9` foreground offers proper WCAG AA contrast (~6.4:1). For theme consistency, nested containers (search frames, entries, buttons) must be updated dynamically, and `insertbackground` must be set to white in dark mode to ensure cursor visibility.
**Action:** Configure the 'done' tag once with high-contrast, theme-appropriate colors, and prepend it to the item's tags sequence to override priority background colors. Programmatically update all nested frames, labels, and entry text cursor attributes during dark/light mode toggles.
