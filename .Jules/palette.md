## 2026-07-15 - Visual Hierarchy of Completed Tasks and Theme Consistency
**Learning:** Completed tasks in a To-Do application should have reduced visual prominence to allow active, pending tasks to stand out. Utilizing a de-emphasized foreground color ensures the user's attention is focused on outstanding work. For accessibility (WCAG AA), we must guarantee a contrast ratio of at least 4.5:1 for this de-emphasized text. In light mode (background `#f8f9fa`), a gray foreground of `#595959` provides ~6.6:1 contrast. In dark mode (background `#212529`), a foreground of `#a9a9a9` provides ~6.4:1 contrast. To override tag priorities in a Tkinter `ttk.Treeview`, the 'done' tag must be placed first in the item's tags sequence and configure both foreground and background explicitly to prevent the active priority colors from bleeding through or reducing contrast. Additionally, full consistency in dark mode requires updating the backgrounds and foregrounds of all intermediate container frames and nested widgets.
**Action:** When designing task lists or toggling themes, ensure a status-override tag like 'done' takes precedence by prepending it to the tag list, and configure theme states comprehensively across all nested frames and components to maintain a seamless user experience.
