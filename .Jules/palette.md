## 2026-10-31 - De-emphasize Completed Tasks in Treeview
**Learning:** In list/table interfaces with priority-based color coding (e.g., bright red, yellow, green), completed tasks distract users and distort the visual hierarchy if they retain saturated alert styling. In Tkinter's `ttk.Treeview`, unlike CSS or Tk `Text`, tag style resolution evaluates tags in order and the FIRST matching option found in the item's tags sequence takes precedence. Therefore, status override tags (such as `done`) must come first in the `tags` sequence to override priority backgrounds and avoid low-contrast color clashes.
**Action:** In `ttk.Treeview`, place higher-priority override tags before base/category tags in the item's `tags` tuple (e.g., `tags = ('done', priority)`), and ensure tag style configurations are updated during theme switches.
