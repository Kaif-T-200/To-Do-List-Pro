# Palette Journal

## 2024-05-23 - Visual De-emphasis for Completed Tasks
**Learning:** To ensure WCAG AA accessibility for 'done' status in a Treeview that uses priority-based background colors, the 'done' tag must explicitly reset both the foreground and background. This prevents the dimmed text from having insufficient contrast against bright priority colors (like red or yellow).
**Action:** Always specify both background and foreground for status-based overrides to guarantee contrast and visual consistency across themes.
