## 2026-05-05 - Visual De-emphasis of Completed Tasks
**Learning:** Visually de-emphasizing completed tasks significantly reduces cognitive load by allowing users to focus on remaining work. Using a muted gray foreground against a neutral background ensures accessibility while providing clear status differentiation.
**Action:** Implement a 'done' tag in the task list that overrides priority-based background colors and uses WCAG AA compliant gray tones for both light and dark modes.
