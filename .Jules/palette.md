## 2025-04-16 - De-emphasizing Completed Tasks
**Learning:** Visually de-emphasizing completed tasks (e.g., using grayed-out text) reduces cognitive load by allowing users to focus on remaining active items while still maintaining a record of accomplishment.
**Action:** Implement a 'done' tag in the task list that applies a theme-aware neutral color to completed rows, ensuring it overrides priority-based background colors.
