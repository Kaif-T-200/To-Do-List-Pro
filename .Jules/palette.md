## 2026-11-09 - Visual Hierarchy and Completion State in Tkinter Treeview
**Learning:** High-saturation priority backgrounds (red/yellow/green) create visual clutter when kept on completed tasks, drawing user focus away from actionable items. In Tkinter `ttk.Treeview`, item styling precedence is determined by tag order (the first tag takes precedence for overlapping configuration options). De-emphasizing completed tasks with muted background/foreground pairs (`#e9ecef`/`#595959` in light mode, `#2c3035`/`#a9a9a9` in dark mode) satisfies WCAG AA contrast (>= 4.5:1) while establishing clear visual hierarchy.
**Action:** When working with status and priority styling in `ttk.Treeview`, prepend status override tags (like `done`) before priority tags and extract tag configuration to a theme update handler rather than reconfiguring tags on every refresh.
