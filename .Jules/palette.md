## 2025-05-14 - Visually de-emphasize completed tasks
**Learning:** Completed tasks should be visually de-emphasized to reduce cognitive load, allowing users to focus on active tasks. Using a muted color for the text and ensuring it remains accessible is key.
**Action:** Use a gray foreground color (e.g., #595959 for light mode, #a9a9a9 for dark mode) for completed tasks to signify they are finished while maintaining WCAG AA contrast.
