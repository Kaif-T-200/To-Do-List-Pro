## 2025-05-15 - Visual De-emphasis for Completed Tasks
**Learning:** In a list-based UI with priority highlighting, completed tasks should visually "recede" to help users focus on remaining work. This is best achieved by overriding color-based priority tags with a neutral, low-contrast "done" tag (foreground #595959 for light, #a9a9a9 for dark).
**Action:** When styling list items with multiple states (e.g., priority AND completion), ensure the completion state tag is applied last to take visual precedence.
