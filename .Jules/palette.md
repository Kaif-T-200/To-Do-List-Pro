## 2025-05-15 - [Initial UX Audit & Enhancements]
**Learning:** Desktop applications built with Tkinter often miss standard interactivity patterns like double-clicking to edit or using the Delete key for removal. Additionally, failing to focus the primary input (search) on launch adds unnecessary friction. Visual hierarchy can be improved by de-emphasizing completed tasks.
**Action:** Always implement standard keyboard/mouse bindings for list-based UIs and ensure the main input field gains focus immediately. Use color/contrast to distinguish between active and completed states.
