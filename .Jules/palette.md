## 2026-11-02 - Visual Hierarchy and Tag Precedence for Completed Tasks in Tkinter Treeview
**Learning:** In Tkinter `ttk.Treeview`, item styling precedence is determined by the order of tags passed to each item: the first matching tag takes precedence over subsequent ones. Applying bright priority colors (red/yellow/green) to completed tasks creates cognitive friction by making completed work visually compete with pending work. Styling completed tasks with a muted palette (#595959 text on #e9ecef background for light mode; #a9a9a9 text on #2c3035 background for dark mode) maintains WCAG AA contrast (> 4.5:1) while establishing clear visual hierarchy.
**Action:** When overriding multi-colored row styles in a `ttk.Treeview`, prepend the status override tag (e.g., `'done'`) before priority tags so that options in earlier tags take precedence, and decouple static `tag_configure` calls from high-frequency refresh loops.
