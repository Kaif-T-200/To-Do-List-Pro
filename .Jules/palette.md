## 2026-07-15 - Visual Hierarchy of Completed Tasks
**Learning:** Using a de-emphasized color (grayed out) for completed tasks improves the visual hierarchy of the task list, allowing users to focus on active tasks while maintaining visibility of accomplishments. To achieve WCAG AA compliance (contrast ratio of at least 4.5:1), the 'done' tag should use foreground #595959 on background #f8f9fa in light mode (~6.6:1 contrast) and foreground #a9a9a9 on background #212529 in dark mode (~6.4:1 contrast). Prepending the 'done' tag first in the item's tags list ensures it takes visual precedence over priority-based background colors because the first tag defining an attribute wins in ttk.Treeview.
**Action:** When overriding multi-colored row styles in a ttk.Treeview (like priority levels), always apply the status override tag (e.g., 'done') first in the tags list/tuple and explicitly define both foreground and background colors to ensure accessibility compliance (WCAG AA). Perform tag configuration operations once (e.g., in `__init__` or a theme-toggling method) rather than inside high-frequency refresh loops (like those triggered by search trace) to avoid performance overhead from redundant UI configuration.
