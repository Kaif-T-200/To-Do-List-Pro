# Palette Journal

## 2026-06-12 - De-emphasizing Completed Tasks
**Learning:** Using a de-emphasized color (grayed out) for completed tasks significantly improves the visual hierarchy of a task list. It allows users to focus on active tasks while still seeing what they have accomplished. Accessibility (WCAG AA) must be maintained by choosing foreground colors that have at least 4.5:1 contrast against both light and dark mode backgrounds.
**Action:** Always provide a visual 'done' state that de-emphasizes the task's content without making it unreadable.
