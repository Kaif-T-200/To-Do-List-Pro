## 2026-06-25 - Visual Hierarchy for Task Completion Status
**Learning:** Completed tasks benefit significantly from visual de-emphasis (e.g., graying out). This improves visual hierarchy, allowing users to focus on active tasks while still seeing their progress. When implementing this over colored priority rows, the 'done' status should take precedence by being applied as the last tag in a ttk.Treeview. Contrast must be carefully managed to ensure WCAG AA compliance (4.5:1 ratio) on both light and dark backgrounds.
**Action:** Use de-emphasized colors (like #595959 on #f8f9fa in Light Mode and #a9a9a9 on #212529 in Dark Mode) for completed states. Always apply the status tag last in the tag list to ensure it overrides background colors from other categories like priority.
