## 2026-07-15 - Visual Hierarchy of Completed Tasks
**Learning:** Using a de-emphasized color (grayed out) for completed tasks improves the visual hierarchy of the task list, allowing users to focus on active tasks while maintaining visibility of accomplishments. To achieve this, the status tag (e.g., 'done') must take visual precedence over priority-based background colors in a `ttk.Treeview` by being prepended/added first in the tags list. For WCAG AA accessibility, the foreground and background of the completed tasks must maintain a contrast ratio of at least 4.5:1. In light mode (neutral background `#f8f9fa`), using a gray foreground like `#595959` achieves a ~6.6:1 contrast, and in dark mode (neutral background `#212529`), a foreground like `#a9a9a9` achieves a ~6.4:1 contrast.
**Action:** Always structure treeview tags so status/override tags are declared first. Explicitly define neutral/app-matching background colors alongside contrast-compliant foreground colors for override tags to prevent priority colors from bleeding through or causing contrast failures. Configure `ttk.Treeview` tags once in initialization or theme toggle methods, rather than on every refresh, to avoid performance overhead in search-filtered interfaces.
