## 2026-07-15 - Visual Hierarchy of Completed Tasks and Theme-Dependent Treeview Styling
**Learning:** Completed tasks are visually prioritized below pending ones to improve visual hierarchy. To accomplish this in `ttk.Treeview` without sacrificing WCAG AA contrast compliance (~4.5:1 ratio), we must style a custom 'done' tag that overrides the background and foreground colors. However, visual precedence in `ttk.Treeview` is determined by tag order (the first tag defining an attribute wins). Prepending 'done' to the item's tags ensures that completed tasks consistently render with de-emphasized colors (e.g. gray foreground `#595959` on neutral `#f8f9fa` in light mode, or `#a9a9a9` on `#212529` in dark mode) instead of priority-specific highlighting.
**Action:** When overriding priority highlighting, prepend/apply the status tag first in the tags list, explicitly specify both foreground and background colors in `tag_configure` to handle overlapping styles, and ensure configuration occurs once per theme toggle (not in high-frequency loops) to maximize rendering performance.
