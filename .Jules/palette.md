## 2026-07-15 - Visual Hierarchy of Completed Tasks
**Learning:** Using a de-emphasized color (grayed out) for completed tasks improves the visual hierarchy of the task list, allowing users to focus on active tasks while maintaining visibility of accomplishments. When overriding multi-colored row styles in a `ttk.Treeview` (like priority levels), always apply the status override tag (e.g., 'done') first in the tags list/tuple and explicitly define both foreground and background colors to ensure accessibility compliance (WCAG AA). Specifically, the 'done' tag must explicitly set its background to match the application's neutral background (e.g., `#f8f9fa` in light mode, `#212529` in dark mode) to maintain proper contrast with the gray foreground. To maintain WCAG AA accessibility for de-emphasized tasks in 'To-Do List Pro', the 'done' tag uses foreground #595959 on background #f8f9fa in light mode (~6.6:1 contrast) and foreground #a9a9a9 on background #212529 in dark mode (~6.4:1 contrast).
**Action:** Prepend/add the 'done' tag first in the tags sequence for a Treeview item, and configure it with high-contrast, accessible foreground and background colors depending on the light or dark theme state.
