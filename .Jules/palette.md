## 2026-05-07 - Visually de-emphasize completed tasks
**Learning:** Completed tasks should be visually distinct from active ones to reduce cognitive load. Using a muted foreground color that still meets WCAG AA standards (e.g., #595959 on #f8f9fa) effectively de-emphasizes finished work without sacrificing readability.
**Action:** When working with list-based task applications, always ensure there is a clear visual distinction for "Done" states beyond just a text label.
