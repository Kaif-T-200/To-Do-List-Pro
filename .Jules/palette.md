## 2026-11-03 - Visual Hierarchy and Completion State in Tkinter Treeview
**Learning:** In task lists with colored priority badges, completed tasks that retain vibrant priority backgrounds (e.g. bright red for High) visually compete with active, pending tasks. Completed items should visually recede using a muted color palette (#595959 on #e9ecef in light mode, #a9a9a9 on #2c3035 in dark mode) while exceeding WCAG AA contrast (5.6:1+). In ttk.Treeview, tag order dictates visual precedence—the first tag listed in an item's tag sequence overrides subsequent tags.
**Action:** When styling status overrides in ttk.Treeview, prepend the status tag (e.g., `tags = ('done', tag) if done else (tag,)`) and configure tags outside the search/filter loop to maintain snappy UI response.
