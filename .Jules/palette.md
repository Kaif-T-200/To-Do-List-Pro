## 2026-07-15 - Visual Hierarchy of Completed Tasks
**Learning:** Using a de-emphasized color (grayed out) for completed tasks improves the visual hierarchy of the task list, allowing users to focus on active tasks while maintaining visibility of accomplishments. When overriding multi-colored row styles in a `ttk.Treeview` (like priority levels), always apply the status override tag (e.g., 'done') first in the tags list/tuple and explicitly define both foreground and background colors to ensure accessibility compliance (WCAG AA). To maintain WCAG AA accessibility in Dark Mode (background `#212529`), use `#a9a9a9` as the foreground color for de-emphasized text (e.g., completed tasks) to ensure a contrast ratio of at least 4.5:1. In Light Mode (background `#f8f9fa`), use `#595959` (~6.6:1 contrast ratio) on background `#f8f9fa` for the 'done' tag.
**Action:** Configure the 'done' tag in `ttk.Treeview` to explicitly define both foreground and background colors matching the current theme state. When inserting rows, prepend 'done' as the first tag so its colors take visual precedence. Avoid high-frequency tag configurations in `refresh_list` to prevent performance overhead.
