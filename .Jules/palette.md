## 2026-03-06 - Visual Hierarchy and Desktop Shortcuts
**Learning:** In list-based task applications, visually de-emphasizing completed tasks (e.g., using a muted gray foreground) significantly improves scannability by letting the user focus on active items. Additionally, implementing standard desktop shortcuts like Double-click to edit and the Delete key to remove items aligns with user mental models for desktop applications.
**Action:** Always consider status-based visual styling and standard keyboard/mouse shortcuts when working with list components in desktop UIs.
