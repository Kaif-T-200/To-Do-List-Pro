## 2026-05-12 - [Visual De-emphasis for Completed Tasks]
**Learning:** Visually de-emphasizing completed tasks using a 'done' tag reduces cognitive load by separating finished work from pending actions. In Tkinter's Treeview, tag precedence for overlapping attributes (like foreground and background colors) is determined by the order of tags in the item's tag sequence; the last tag that defines a specific attribute takes precedence.
**Action:** Always provide clear visual distinction for terminal states (like 'done' or 'canceled') in list-based UIs to improve scanability. Ensure that override tags are applied last in the widget's tag sequence.
