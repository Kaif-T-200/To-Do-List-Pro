# Palette Journal

## 2025-05-14 - Visually de-emphasizing completed tasks
**Learning:** Completed tasks often clutter the view, making it harder to focus on pending items. Muting their appearance (graying out) provides immediate visual feedback and better information hierarchy. In Tkinter Treeview, tag order matters for attribute precedence.
**Action:** Apply a 'done' tag as the last tag in the sequence for completed items, and use WCAG AA compliant colors for the muted state in both light and dark modes.
