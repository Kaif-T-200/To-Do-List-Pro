# Palette Journal

## 2025-05-14 - Visual De-emphasis for Completed Tasks
**Learning:** Completed tasks should be visually de-emphasized to reduce cognitive load and help users focus on remaining work. Using a gray foreground and a matching background for the 'done' tag in a `ttk.Treeview` ensures accessibility while providing clear visual feedback.
**Action:** Always provide visual feedback for interactions, including de-emphasizing completed items in list-based UIs.
