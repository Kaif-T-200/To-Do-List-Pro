## 2026-11-10 - Visual De-emphasis and Tag Precedence for Completed Items in Tkinter Treeview
**Learning:** In list views with colored priority indicators (e.g. bright red, yellow, green), completed items that retain full priority saturation create visual noise and compete for user attention. De-emphasizing completed tasks with a muted background (#e9ecef in light, #2c3035 in dark) and muted text (#595959 in light, #a9a9a9 in dark) preserves WCAG AA contrast (5.6:1 - 5.9:1) while immediately communicating completed status. Furthermore, in Tkinter ttk.Treeview, tag order matters: earlier tags take visual precedence, so status override tags (like 'done') must precede priority tags in the tuple.
**Action:** When overriding multi-colored row styles in ttk.Treeview, prepend the status override tag before priority tags and ensure muted foreground/background colors still pass WCAG AA contrast standards across both light and dark themes.
