# Palette UX & Accessibility Journal

## 2026-07-15 - Visual Hierarchy of Completed Tasks
**Learning:** Completed tasks should be de-emphasized visually to allow users to focus on active tasks. Simply keeping priority-based highlights (which can be loud or bright) can distract from what still needs to be done.
**Action:** Implement a 'done' tag in the task list Treeview to apply a visually distinct style to completed tasks, ensuring WCAG AA contrast compliance in both light and dark modes.
