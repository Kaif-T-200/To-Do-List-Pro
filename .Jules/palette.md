# Palette's UX/Accessibility Journal

## 2025-05-15 - Visually de-emphasizing completed tasks
**Learning:** Completed tasks can clutter the UI if they maintain the same visual weight as active tasks. De-emphasizing them with lower contrast reduces cognitive load and helps users focus on remaining work.
**Action:** Use a gray foreground and a neutral background for 'Done' tasks to ensure they are visually distinct from pending tasks while remaining accessible (WCAG AA).
