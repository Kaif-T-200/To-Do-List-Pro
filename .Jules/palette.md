## 2026-04-29 - Visually de-emphasize completed tasks
**Learning:** Completed tasks should be visually de-emphasized (e.g., using gray text) to reduce cognitive load, allowing users to focus on remaining tasks. In a priority-colored list, this requires carefully managing tag precedence and background colors to maintain accessibility.
**Action:** Use a 'done' tag in the Treeview with a lower-contrast foreground and ensure it overrides priority-based background colors when a task is completed.
