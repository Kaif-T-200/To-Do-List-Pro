# Palette's UX Journal

## 2026-05-06 - Visual de-emphasis for completed tasks
**Learning:** Visually de-emphasizing completed tasks (e.g., using gray text) reduces cognitive load by allowing users to focus on remaining items. To ensure WCAG AA compliance (4.5:1 ratio), specific gray shades must be used: #595959 for light mode (7:1 ratio) and #a9a9a9 for dark mode (4.5:1 ratio).
**Action:** Always use theme-aware gray shades for de-emphasized text and explicitly set the background color to override priority highlights when a task is completed, ensuring contrast is maintained.
