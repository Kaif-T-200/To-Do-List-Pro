## 2026-07-15 - Visual Hierarchy of Completed Tasks
**Learning:** Graying out (de-emphasizing) completed tasks improves visual hierarchy by letting users focus on active tasks while retaining visibility of accomplishments. In a `ttk.Treeview` widget, applying a 'done' tag with custom styling allows immediate visual feedback. To ensure WCAG AA contrast compliance (~4.5:1 ratio), we use foreground `#595959` on background `#f8f9fa` in light mode (contrast ~6.6:1), and `#a9a9a9` on `#212529` in dark mode (contrast ~6.4:1). When using priority background highlighting alongside completion styling, we must override the priority backgrounds with the completed state background. In `ttk.Treeview`, the tag that defines a specific attribute and appears first in the item's `tags` tuple takes visual precedence.
**Action:** When updating a `ttk.Treeview` list, prepend the 'done' tag in the tags list if status is 'Done', and perform the tag configuration once in a centralized/lazy method to avoid performance degradation in high-frequency update loops.
