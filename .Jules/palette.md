## 2026-11-05 - Visual Hierarchy for Completed Tasks in Tkinter Treeview
**Learning:** Priority color coding (e.g., loud red/yellow) on completed tasks causes visual clutter and fails to communicate task completion state at a glance. In Tkinter's `ttk.Treeview`, the first matching tag in an item's tag sequence determines visual property precedence (unlike CSS). Prepended status tags (like `'done'`) allow overriding loud priority backgrounds with accessible, de-emphasized colors (`#e9ecef` / `#595959` in light mode, `#2c3035` / `#a9a9a9` in dark mode) while preserving underlying priority metadata.
**Action:** When working with Tkinter `ttk.Treeview` tables with multi-colored rows, prepend state override tags (such as `'done'`) before property tags to maintain clear visual hierarchy without discarding item metadata.
