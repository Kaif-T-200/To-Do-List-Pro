# Palette's Journal - To-Do List Pro

## 2026-05-11 - Completed Task De-emphasis
**Learning:** In a task management app, completed items should be visually de-emphasized to reduce cognitive load and allow users to focus on remaining work. Using a grayed-out foreground and a neutral background (matching the app's background) ensures they don't compete with active tasks for attention while remaining readable.
**Action:** Apply a 'done' tag in the Treeview that overrides priority-based background colors and uses WCAG-compliant gray tones for text.
