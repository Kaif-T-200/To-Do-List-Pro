## 2025-05-15 - Visually de-emphasizing completed tasks
**Learning:** Completed tasks should be visually distinguished from pending ones to reduce cognitive load. Using a muted foreground color (e.g., #595959 for light mode) provides clear status feedback while maintaining WCAG AA accessibility.
**Action:** When a task is marked as "Done", apply a "done" tag that overrides priority-based background colors and uses a de-emphasized text color.
