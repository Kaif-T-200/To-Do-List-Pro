## 2026-11-10 - Visual Hierarchy and Completed Task State in Tkinter Treeview
**Learning:** In Tkinter `ttk.Treeview`, items configured with vibrant row background colors (such as priority badges) remain visually dominant even when marked 'Done', disrupting visual hierarchy and task scanning. Furthermore, `tree.tag_configure` visual precedence is dictated by the order of tags in the item's `tags` tuple—earlier tags take precedence. To de-emphasize completed items without sacrificing readability, a muted tag (`#595959` on `#e9ecef` in light mode, `#a9a9a9` on `#2c3035` in dark mode, both >4.5:1 WCAG AA) must be prepended before priority tags. Reconfiguring tags repeatedly in search trace loops causes needless UI churn and should be moved to theme update methods.
**Action:** When overriding multi-colored row styles in a `ttk.Treeview`, prepend the status override tag before priority tags, and ensure tag configurations are coupled with theme toggling rather than high-frequency refresh events.
