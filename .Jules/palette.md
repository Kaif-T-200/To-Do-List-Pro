## 2025-01-24 - Visual De-emphasis for Task Completion
**Learning:** In task-heavy UIs, visually de-emphasizing completed tasks significantly reduces cognitive load. For Tkinter `ttk.Treeview`, this requires careful tag ordering (last tag wins) and theme-aware color configuration to maintain WCAG AA compliance (e.g., contrast against both light and dark backgrounds). Overlapping tags must be handled explicitly if background colors need to be overridden.
**Action:** Apply a 'done' tag last in the Treeview's `tags` sequence. Use `#595959` (light mode) and `#a9a9a9` (dark mode) for foreground colors to ensure ~7:1 and ~4.5:1 contrast ratios respectively. Explicitly set the background color in the 'done' tag configuration to match the theme background when it should override priority-based row highlighting.
