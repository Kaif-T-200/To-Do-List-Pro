## 2026-07-15 - Visual Hierarchy of Completed Tasks
**Learning:** Using a de-emphasized color (grayed out) for completed tasks improves the visual hierarchy of the task list, allowing users to focus on active tasks while maintaining visibility of accomplishments. To maintain WCAG AA compliance, a 'done' tag should use foreground #595959 on background #f8f9fa in light mode (approx 6.6:1 contrast) and foreground #a9a9a9 on background #212529 in dark mode (approx 6.4:1 contrast). To ensure the tag applies properly and overrides priority-based background colors, the 'done' tag should explicitly override both the foreground and background and be placed last in the Treeview tag tuple.
**Action:** When a task's status is 'Done', append 'done' to its tags list and configure the 'done' tag with the appropriate accessible colors based on the active theme.
