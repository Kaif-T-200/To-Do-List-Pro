## 2025-05-15 - Visually de-emphasizing completed tasks
**Learning:** Completed tasks often clutter the UI, making it harder to focus on remaining work. Using a muted color for finished tasks reduces cognitive load and provides a clear visual distinction.
**Action:** Use WCAG AA compliant gray tones (#595959 for light mode, #a9a9a9 for dark mode) to de-emphasize 'Done' tasks in list views.
