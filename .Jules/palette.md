## 2026-04-24 - Visual De-emphasis for Completed Tasks
**Learning:** Visually de-emphasizing completed tasks by reducing color contrast (e.g., using gray text) and removing high-priority background colors significantly reduces cognitive load. It allows users to focus on remaining tasks while still keeping a record of what has been accomplished, fulfilling both organizational and psychological needs.
**Action:** When a task is marked as "Done", apply a "muted" style that overrides any priority-based coloring to provide clear visual feedback of completion.
