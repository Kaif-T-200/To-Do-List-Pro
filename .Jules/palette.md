## 2026-11-07 - Visual Hierarchy of Completed Tasks in Treeview
**Learning:** In task management UIs, giving completed tasks the same vivid priority background colors as pending tasks clutters the list and strains visual scannability. Visually de-emphasizing completed tasks with a subdued background and WCAG AA-compliant foreground color creates a clean visual hierarchy, allowing users to focus on active tasks. In Tkinter's `ttk.Treeview`, the first tag listed in an item's `tags` tuple takes precedence over subsequent tags for matching styling options; therefore, status override tags like `'done'` must precede priority tags (e.g. `('done', priority)`).
**Action:** Always place status override tags first in the Treeview item's `tags` sequence, and centralize style definitions in dedicated methods rather than configuring tags within frequent refresh loops.
