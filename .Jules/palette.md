# Palette Journal

## 2024-05-14 - Visual de-emphasis for completed tasks
**Learning:** In list-based applications, active and completed tasks competing for visual attention can increase cognitive load. Visually de-emphasizing completed tasks using WCAG AA compliant gray tones (#595959 for light, #a9a9a9 for dark) effectively guides the user's focus to pending items while maintaining accessibility.
**Action:** Always provide distinct visual states for "done" vs "pending" items in lists, ensuring that the de-emphasized state still meets contrast requirements.
