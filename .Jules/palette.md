## 2026-07-15 - Visual Hierarchy of Completed Tasks in Treeview
**Learning:** Using a de-emphasized color (grayed out) for completed tasks improves the visual hierarchy of the task list, allowing users to focus on active tasks while maintaining visibility of achievements. In `ttk.Treeview`, defining a dedicated 'done' tag that explicitly sets both the foreground (e.g., #595959 in light mode, #a9a9a9 in dark mode) and background (matching the neutral background) ensures WCAG AA contrast compliance and prevents priority background colors from overriding the completed state.
**Action:** Apply status override tags last in the Treeview item's tags tuple so that status styling takes precedence over category/priority-based tags, and perform all `tag_configure` configurations once (e.g., in `__init__` or theme toggle) to avoid redundant configurations in high-frequency redraw loops.
