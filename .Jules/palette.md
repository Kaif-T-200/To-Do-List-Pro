## 2026-07-15 - Visual Hierarchy of Completed Tasks
**Learning:** Using a de-emphasized color (grayed out) for completed tasks improves the visual hierarchy of the task list, allowing users to focus on active tasks while maintaining visibility of accomplishments. When overriding multi-colored row styles in a `ttk.Treeview` (like priority levels), always apply the status override tag (e.g., 'done') first in the tags list/tuple and explicitly define both foreground and background colors to ensure accessibility compliance (WCAG AA). Specifically, in Dark Mode, foreground #a9a9a9 on background #212529 satisfies WCAG AA contrast ratio of at least 4.5:1. In Light Mode, foreground #595959 on background #f8f9fa satisfies the same requirement.
**Action:** Implement a 'done' tag in `ttk.Treeview` configured with WCAG AA compliant colors depending on the active theme, and prepend this tag to the items' tags sequence to ensure it visual-precedes other styling.
